# SFHacks-2026

## SFPulse AI — Civic & Environmental Intelligence Platform

Created for **SF Hacks 2026** (GDG AI Hackathon at San Francisco State University).

### Features
- **San Francisco Peninsula Telemetry Grid**: Interactive vector cartography with live microclimate, AQI, tree canopy coverage, and solar generation across 10 SF districts (including SFSU, Mission, SOMA, and Ocean Beach).
- **Multi-Head AI Incident & Vision Classifier**: 4-head ML inference pipeline outputting category, urgency SLA, carbon drawdown potential, and automated municipal work order dispatch.
- **What-If Climate Action Simulator**: Dynamic modeling of urban tree canopy planting, cool pavements, zero-emission Muni expansion, and compost diversion with real-time CO2, healthcare savings, and heat island mitigation metrics.
- **Embedded IoT & LoRaWAN Sensor Fleet**: Real-time telemetry monitoring simulated ESP32-S3, Nordic nRF9160, and gateway nodes with live anomaly detection.

### Development
```bash
npm install
npm run dev
```
